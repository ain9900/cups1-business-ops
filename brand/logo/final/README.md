**Colours (measured from the master):** Navy #00213C · Orange #FE7702 · Leaf green #67A42D.
- Navy text on white 16.4:1. Orange on white is 2.67:1: use orange for the logo, large shapes and buttons **with navy text** (6.1:1), not for small text. For orange text use #B34E00 (5.2:1).
- Leaf green is for the logo only (3.0:1 on white).
**Minimum sizes:** full logo with tagline ≥ 300px / 75mm wide; no-tagline ≥ 160px; navbar version ≥ 28px tall; below that use the icon.
**Notes:** the masters are raster images (PNG). For large print (signage, cartons, printed cups) a printer will want a vector file: ask a designer to trace the master into SVG/AI/EPS, or use `brand/logo/cups1-v2/` (Claude's vector rebuild, upright lettering) as a starting point. The leaf implies an eco benefit: back it with documents (claims rule). Use ™ until registered.
